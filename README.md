# 바로보기 (Barobogi) · Android

사진·카메라·웹의 글을 번역해 보여 주는 Android 앱 바로보기의 배포 저장소입니다. 앱 소스는 이 저장소에 없고, 서명된 APK만 [릴리스](https://github.com/armsone/Barobogi-Android/releases)로 제공합니다.

- 패키지: `com.hanstree.barobogi`
- 설치 파일: 릴리스의 `Barobogi-Android-{버전}.apk` (Android 8.0 이상)
- 릴리스 본문에 `Android-Version-Code`와 `Build-Number`를 따로 적습니다.
- 소개와 내려받기: https://hanstree.com/apps/barobogi
